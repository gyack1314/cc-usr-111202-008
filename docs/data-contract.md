# 优先结局资料

id全局唯一；stratum为固定分析层，arm为treatment/control。survival和progression都带非负time及布尔event，时间单位同为研究日。time为该结局事件或独立删失的时点，并非访视修订记录。两个删失同刻仍未知；时间层仅两个已观察事件同刻才是确定平局。质量变化quality_change可null，正值表示改善。

stratum_weights为预先给定且和为1的正分数，不根据组样本数改变。每层每一治疗与每一对照构成一个配对，U_w与U_l的分母均为全部跨组配对数，包括最终平局和不可比较。行/列向量样本协方差按人数减1归一；治疗与对照各独立抽样，不同层独立。W/L及其delta区间不把这种观察比较自动解释为因果。

已有domain只清点分层人数和缺失，不比较配对或求投影方差。
